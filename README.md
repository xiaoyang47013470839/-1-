# 信用卡客户下月违约风险分析系统（界面模块）

计算机金融学导论 · 课程项目一 · 组内「界面设计」分工交付。

本界面读取课程真实数据与组员（模型训练、测试优化两棒）交付的模型文件，
完成题目要求的三个核心页面：**数据概览 / 模型比较 / 客户风险演示**，
另设**最终评价**页固定展示锁定的测试集结果。

## 运行环境

- Python 3.10 及以上（开发时使用 Python 3.14）
- 依赖：`streamlit`、`pandas`、`numpy`、`scikit-learn`、`plotly`

## 启动步骤

```bash
# 1. 安装依赖（首次运行）
pip install streamlit pandas numpy scikit-learn plotly

# 2. 启动界面（在本文件夹下执行）
streamlit run app.py
```

启动后浏览器会自动打开 `http://localhost:8501`；首次加载约需数秒
（读取 3 万条数据 + 在训练集上拟合对比模型）。

## 页面说明

| 页面 | 内容 | 对应题目要求 |
| --- | --- | --- |
| 📊 数据概览 | 统计卡片（总样本数、违约率、违约客户数、缺失值、重复编号）＋ 数据划分与各组违约率表 ＋ 授信额度/年龄分布图 ＋ 可切换月份的还款状态分布图 ＋ 编码说明 | 数据核查、两种以上图表 |
| ⚖️ 模型比较 | 基线 / 逻辑回归 / 随机森林在**验证集**上的对比；阈值滑块实时更新精确率、召回率、报警人数；阈值-指标曲线 | 训练与选型、验证集阈值选择依据 |
| ✅ 最终评价 | 锁定模型 + 阈值后测试集的 ROC-AUC、精确率、召回率、混淆矩阵、漏判/误判人数、ROC 曲线 | 最终评价（仅评价一次，不重复调参） |
| 👤 客户风险演示 | 按客户编号查询或随机抽取记录，展示主要信息、违约概率、报警阈值与风险提示；测试集记录单独标示事后真实标签 | 个案演示 |

## 界面与数据口径约定

- 模型比较页中的对比模型**只在训练集拟合**（标准化放在 Pipeline 内），阈值只用验证集选择
  （规则：召回率 ≥ 70% 的候选中精确率最高），测试集结果只出现在「最终评价」页。
- 最终评价页与客户演示页直接加载组员交付的 `rf_best_model.pkl`、`test_metrics.json`、
  `test_predictions.csv`，界面不修改指标口径。
- 还款状态的 `-2 / -1` 等负值是正常编码（无消费 / 全额还款），界面已按编码含义展示，不作为缺失值。
- 敏感属性（性别、年龄、教育、婚姻）仅用于公平性讨论；界面全程提示「相关性不等于因果关系，
  结果仅作教学示例，不用于真实授信决策」。

## 界面分工说明（供个人报告引用）

- 负责文件：`app.py`（全部四个页面）、`README.md`。
- 关键测试：① 验证页内重训的随机森林与组员交付指标一致（AUC 差异 < 0.001，来自
  scikit-learn 版本差异）；② 演示页输入不存在的客户编号时给出有效范围提示；
  ③ 缺少模型/指标文件时页面给出明确错误提示而非崩溃；④ 浏览器实测四个页面切换后无控件残留，
  实测数值：概览页 30,000 条 / 违约率 22.12% / record_id 重复 0 / 缺失值 0；
  比较页随机森林验证集 AUC 0.7787、自动阈值 0.2200；最终评价页 AUC 0.7587、阈值 0.2167、
  混淆矩阵 2489 / 1016 / 329 / 667；演示页客户 #6 概率 48.00% > 阈值 21.67% 判为高风险，
  且事后真实标签与预测结果分开标示；⑤ 统计卡片布局由 5 列改为 3+2 两行并精简过长数值后，
  在窄窗口下四个页面均不再出现数值被省略号截断（如 `30,...`、`0.7...`）的情况。

## 关键 AI 交互（供 AI 交互日志与个人报告引用）

开发全程使用 AI 编程助手（Trae），按「自然语言描述需求 → 生成代码 → 本人运行测试 →
反馈问题 → 再修改」的循环推进，主要轮次如下：

1. **需求描述（生成初版）**：向 AI 说明——用 Streamlit 做界面，读取课程
   `01_credit_default.csv` 与组员交付的 `rf_best_model.pkl` / `test_metrics.json` /
   `test_predictions.csv`；口径为训练集拟合、验证集选阈值、测试集只评一次；
   页面至少含数据概览 / 模型比较 / 客户风险演示。AI 返回 `app.py` 初版：四个页面函数
   ＋四个缓存加载器＋阈值选择函数 `pick_threshold`。
2. **界面结构重构（本人实测发现并反馈）**：初版用单文件内的 `st.sidebar.radio` 切换页面，
   本人实测发现切换后上一页最后两个 `st.metric` 卡片仍残留可见。向 AI 描述该现象后，
   AI 建议改用 `st.navigation` + `st.Page` 多页面模式（每次切换渲染全新容器）。
   采纳重构后残留消失，四页实测干净。
3. **代码缺陷修正**：AI 初版在取训练/验证集标签处写成
   `y_tr.to_numpy() and y_va.to_numpy()`（用逻辑与连接两个数组），本人核对后改为
   `y_va.to_numpy()`。
4. **弃用警告处理**：初版 `st.plotly_chart(..., use_container_width=True)` 触发 Streamlit
   弃用警告，按 AI 提示全文替换为 `width='stretch'`。
5. **口径一致性核验**：本人把界面内重训的随机森林与组员交付模型对照——验证集 AUC 0.7787、
   测试集 AUC 0.7587，两者差异小于 0.001，经查为 scikit-learn 版本差异（本机 1.9.1）。
   确认口径一致后，才把「最终评价」页改为直接读取组员锁定的 json / csv，界面不重复调参。
