# 界面设计这一棒 · 交接素材清单

> 用途：给负责「文案汇报」的同学写 PPT、总结报告和答辩讲稿用。
> 对应题目：计算机金融学导论 · 课程项目一 · 信用卡客户下月违约风险分析系统

## 一、这一棒做了什么（一句话）

用 Streamlit 实现题目要求的界面：**四个可切换页面**，读取课程真实数据（30,000 条）与
组员交付的锁定模型文件，页面上的每个数值都由程序实际计算或加载，**没有静态设计稿、没有手填指标**。

## 二、页面 ↔ 题目验收要求对应表

| 页面 | 题目要求 | 我们的实现 |
| --- | --- | --- |
| 📊 数据概览 | 读取 CSV，按 split 展示样本量、违约率、缺失值、record_id 重复数；绘制授信额度、年龄、还款状态分布 | 5 个统计卡片 + 三集违约率表 + 授信额度/年龄双直方图 + 可切换月份的还款状态柱状图 + 编码说明折叠面板 |
| ⚖️ 模型比较 | 实现全判不违约基线、逻辑回归、至少一种树模型；预处理仅在训练集拟合；验证集比较模型并选阈值、显示依据 | 三模型单选切换；界面内自动重训（LR + RF 仅用训练集拟合）；阈值滑块实时更新精确率/召回率/报警人数；阈值-指标曲线标注「自动阈值」 |
| ✅ 最终评价 | 锁定模型与阈值后**只评价一次**测试集；展示 ROC-AUC、违约类精确率、召回率、混淆矩阵、误判漏判人数 | 直接加载组员交付的 `test_metrics.json` 与 `test_predictions.csv`，界面不重复调参；混淆矩阵 + 漏判/误判卡片 + ROC 曲线 |
| 👤 客户风险演示 | 输入或选择一条记录，展示风险概率、阈值、风险提示和主要输入信息；测试记录须把事后真实标签与预测分开标示 | 编号查询 / 随机抽取两个控件；主要信息卡片 + 六个月还款明细表；概率 vs 阈值大字结论；测试集记录用独立边框块标示「事后信息」 |

## 三、答辩演示路径（建议按这个顺序点）

1. 启动：`streamlit run app.py` → 浏览器打开 `http://localhost:8501`
2. **数据概览**：先讲统计卡片（30,000 条 / 违约率 22.12% / 无缺失无重复），再讲三集划分表，最后滚到两张分布图和可切换月份的还款状态图——注意强调「-2 = 无消费、-1 = 全额还款是编码，不是缺失值」
3. **模型比较**：讲「三个模型都只在训练集拟合」→ 点选「随机森林」→ 指出 AUC 0.7787、自动阈值 0.2200 → **拖动阈值滑块**，让老师看到精确率/召回率/报警人数实时变化（这是交互性的直接证据）
4. **最终评价**：说明这页直接读组员文件、测试集只评一次 → 指混淆矩阵 2489 / 1016 / 329 / 667 → 讲漏判与误判的代价权衡
5. **客户风险演示**：输入 6 → 显示客户 #6 概率 48.00% > 阈值 21.67% → 高风险提示 → 最后指那块「事后信息」说明测试集记录的真实标签是**分开标示**的

## 五、口径三句话（写进报告和 PPT 的核心）

1. **只在训练集拟合**预处理和模型（标准化放在 Pipeline 内，只对训练集 fit）。
2. **只用验证集**选模型和报警阈值（规则：召回率 ≥ 70% 的候选中精确率最高）。
3. **测试集只评价一次**，结果直接来自组员锁定的文件，界面不重复调参、不修改指标。

## 六、必须体现的合规表述

- 性别、年龄、教育、婚姻属于**敏感属性**，仅用于课堂公平性讨论；
- 统计**相关性不等于因果关系**，不能解释为「这些属性导致违约」；
- 结果**仅作教学示例，不作为授信决策依据**；
- 漏判（FN）可能增加损失，误判（FP）可能影响正常客户 —— 阈值就是这两者的权衡。

```bash
pip install streamlit pandas numpy scikit-learn plotly

```
